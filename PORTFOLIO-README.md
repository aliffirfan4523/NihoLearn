# Portfolio — Projects

## NihoLearn — Japanese (JLPT) Learning Platform

**Tech Stack:** Next.js, TypeScript, Tailwind CSS, Prisma, SQLite, Zustand, Recharts

> NihoLearn combines everything you need to master Japanese in one place — complete JLPT content from N5 to N1, an interactive kana system, comprehensive progress tracking for kana, vocabulary, grammar, and kanji, and a learning roadmap that guides you from beginner to advanced.

- Built a full-stack web app that combines everything needed to master Japanese in one place, covering complete JLPT content from N5 to N1 plus hiragana and katakana.
- Engineered an interactive kana system with custom SVG stroke-order tracing, Japanese SpeechSynthesis pronunciation, and mnemonic flashcards.
- Designed a progress-tracking system for kana, vocabulary, grammar, and kanji, persisted to a SQLite database via Prisma with an in-app data editor.
- Built a gamified learning experience with a structured roadmap guiding users from beginner to advanced, plus a responsive light-theme UI with collapsible sidebar and progress dashboards.
- Actively extending with SRS-style review, study-session logging, statistics charts, and practice games.
